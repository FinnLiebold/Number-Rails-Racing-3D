HOW TO ADD SPELLING-BEE AUDIO MANUALLY
=======================================
1. In ElevenLabs, generate each FRENCH word below with the "Paul K" voice.
2. Download the MP3.
3. Rename it EXACTLY to the filename shown (right column).
4. Put all the files in a folder called "audio" next to index.html:
   NumberRailGame\audio\le_chien.mp3  (etc.)
The Spelling Bee uses them automatically. Any word you skip just uses the
browser voice instead - so you can do as many or as few as you like.
